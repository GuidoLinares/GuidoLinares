## Sobre mí

Desarrollo y arquitecturo sistemas internos para una organización de medicina prepaga con
más de 100.000 afiliados. Mi trabajo va del backend a la base: APIs en NestJS, servicios de
automatización en Python sobre AWS, y administración de una instancia SQL Server de producción
donde diagnostico bloqueos, escribo stored procedures y diseño procesos de carga masiva.

- 🏥 **Full Stack Developer & Database Architect** en Grupo ROISA — sistemas internos, integraciones y automatización de procesos
- 🗄️ **SQL Server en producción**: análisis de cadenas de bloqueo, Extended Events, triggers de sesión, SPs de negocio
- 🤖 **Automatización con IA**: agentes internos, capacitaciones de Claude Code al equipo, certificaciones de Anthropic
- 🎓 Cursando **Ingeniería Informática** en la Universidad Nacional de La Matanza
- ✈️ Técnico egresado del **INAC-CIATA** (Aviación Civil)

> ⚠️ La mayor parte de mi trabajo diario vive en repositorios privados corporativos, así que las
> estadísticas de abajo no reflejan el stack que uso en producción. Para eso está la sección de tecnologías.
